### 🚀 Featured Project: MSR (Monitoring Submarine Robot)

**Goal:** An autonomous/remotely operated submarine designed to monitor the health of coral reefs in the **Red Sea (Aqaba)**.

* **Architecture:** A "Split-Brain" system to optimize processing power.
    * **Edge:** NVIDIA Jetson Nano handles camera streaming and motor control via Arduino.
    * **Core:** A laptop runs a custom-trained **YOLOv11** model for real-time high-fidelity coral classification.
* **Hardware:** Custom-built 4.7kg chassis (40cm length) with 3 brushless motors and ESCs.
* **Impact:** Automating environmental monitoring to protect marine life in Jordan.
